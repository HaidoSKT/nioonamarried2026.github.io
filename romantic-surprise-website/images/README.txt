Drop your romantic photos together into this folder!
For example:
- photo1.jpg
- photo2.jpg
- photo3.jpg
- photo4.jpg

Then in config.js, set:
  photos: [
    { url: "images/photo1.jpg", caption: "Our first date 🌸" },
    { url: "images/photo2.jpg", caption: "My favorite view is you ✨" },
    ...
  ]

You can also use online image links (Google Photos public link, Imgur, Cloudinary, etc.).
